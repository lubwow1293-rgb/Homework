# Виджет «Последние успешные операции»

Виджет для отображения последних успешных банковских операций клиента (покупки, переводы, пополнения). Компонент разработан с упором на строгую типизацию, безопасность данных и легкую встраиваемость в основное приложение банка.

## Демонстрация

*Пример работы виджета: список из 5 последних операций с иконками категорий, маскированными номерами карт и датами в формате DD.MM.YYYY.*

## Технологический стек

*   **Язык:** Python $\ge$ 3.14
*   **Управление зависимостями:** Poetry
*   **Статическая типизация:** Mypy (строгий режим, `disallow_untyped_defs`)
*   **Форматирование кода:** Black (длина строки 119)
*   **Сортировка импортов:** isort
*   **Линтер:** flake8
*   **Валидация данных:** Pydantic (внутренняя)

## Установка

Проект использует изолированные окружения Poetry.

```bash
# Клонирование репозитория
git clone [URL_ВАШЕГО_РЕПОЗИТОРИЯ]
cd [ИМЯ_ПАПКИ]

# Создание виртуального окружения и установка зависимостей
poetry install

# Установка зависимостей для линтинга и разработки
