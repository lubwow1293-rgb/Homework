# Виджет «Последние успешные операции»

Виджет для отображения последних успешных банковских операций клиента (покупки, переводы, пополнения). Компонент разработан с упором на строгую типизацию, безопасность данных и легкую встраиваемость в основное приложение банка.

## Демонстрация

*Пример работы виджета: список из 5 последних операций с иконками категорий, маскированными номерами карт и датами в формате DD.MM.YYYY.*

## Технологический стек

*   **Язык:** Python $\ge$ 3.14
*   **Управление зависимостями:** Poetry
*   **Статическая типизация:** Mypy (строгий режим, `disallow_untyped_defs`)
*   **Форматирование кода:** Black (длина строки 119)
*   **Сортировка импортов:** isort
*   **Линтер:** flake8
*   **Валидация данных:** Pydantic (внутренняя)

## Установка

Проект использует изолированные окружения Poetry.

```bash
# Клонирование репозитория
git clone [URL_ВАШЕГО_РЕПОЗИТОРИЯ]
cd [ИМЯ_ПАПКИ]

# Создание виртуального окружения и установка зависимостей
poetry install

# Установка зависимостей для линтинга и разработки
poetry install --with lint
```
## Тестирование и качество кода

Проект использует комплексный подход к обеспечению качества: 
от строгой статической типизации до полного покрытия кода тестами.

## Покрытие тестами

Весь код проекта покрыт unit-тестами. Для запуска тестов используется pytest:

```bash
# Запуск всех тестов
poetry run pytest

# Запуск с отображением покрытия кода
poetry run pytest --cov=src --cov-report=term-missing
```
Текущее покрытие кода превышает 95%, что гарантирует надёжность работы всех компонентов.

## Статический анализ и линтинг
Для поддержания высокого качества кода и соответствия стандартам PEP 8 используются следующие инструменты:

*  **Mypy** — строгая статическая типизация (--disallow-untyped-defs).
*  **Black** — автоматическое форматирование кода (длина строки 119).
*  **isort** — сортировка импортов.
*  **flake8** — линтинг и поиск потенциальных ошибок.

Запуск всех проверок качества одной командой:

```bash
poetry run task lint
```
